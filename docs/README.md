# Gobierno de la documentación

| Ruta | Estado | Uso |
|---|---|---|
| `cadena-farmacias-docs/` | Canónico | Negocio, procesos, requisitos, dominio, arquitectura, datos, API, seguridad, UX, pruebas, DevOps y roadmap. |
| `arquitectura/` | Legado | Diseño técnico anterior; útil como antecedente, no como fuente de alcance. |
| `sprint/` | Sustituido | Plan temporal anterior; no representa compromiso vigente. |
| `decisiones-adr/` | Legado | ADR anteriores; una decisión solo sigue vigente si fue incorporada al índice ADR canónico. |
| `db/` | Borrador legado | SQL de diseño no ejecutado por Flyway. |
| `cadena-farmacias-documentacion-md.zip` | Generado | Copia de distribución regenerable; nunca prevalece sobre los Markdown fuente. |
